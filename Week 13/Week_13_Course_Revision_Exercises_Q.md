### Exercise 1 Question: Process Pool with Pipes, `select()`, Signals, and File Descriptors

You need to implement a simple process pool.

The parent process creates `N` worker child processes. Each worker receives jobs from the parent through an anonymous pipe. Each job is an integer. The worker computes:

```c
result = job * job;
```

and sends the result back to the parent through another anonymous pipe.

**The parent must:**
1. Create `N` workers.
2. Send jobs `1, 2, ..., M` to workers.
3. Use `select()` to receive results from all workers.
4. Stop workers gracefully by sending a special stop job `-1`.
5. Reap all children using `waitpid()`.
6. Handle `SIGINT` by stopping all workers and exiting cleanly.

You may assume:

```text
N > 0
M > 0
Each message is exactly one int.
```

**Write the key code or detailed pseudocode for:**

```c
void create_workers(int N);
void send_job(int worker, int job);
void parent_loop(int M);
void cleanup(void);
```

Also explain which pipe ends each process must close.
